# 공유기 설정 가이드 (LG U+ HGWD-1GR)

작성일: 2026-09-18

집 PC에서 발헤임 서버를 돌리려면 공유기에서 세 가지를 해야 한다.

| 순서 | 할 일 | 왜 |
|---|---|---|
| 1 | 관리자 비밀번호 확인하고 변경 | 기본 비밀번호로는 포트포워딩이 막힌다 |
| 2 | 이 PC에 IP 고정 할당 | IP가 바뀌면 포트포워딩이 엉뚱한 곳을 가리킨다 |
| 3 | 포트포워딩 (UDP 2456-2457) | 이게 없으면 친구들이 접속할 수 없다 |

여기에 PC 쪽에서 한 가지 더.

| 4 | Wi-Fi 끄기 | 유선과 무선이 같이 붙어 있어 경로가 애매해진다 |

## 이 PC 정보 (설정할 때 입력할 값)

```
내부 IP (이더넷) : 192.168.219.117
MAC 주소         : D8-43-AE-28-0F-76
공유기 주소      : http://192.168.219.1
```

---

# 1. 관리자 비밀번호

## 1-1. 기본 비밀번호 찾기

공유기 본체의 **밑면 또는 뒷면 라벨**을 본다. 이렇게 적혀 있다.

```
웹 주소     : 192.168.219.1
웹admin암호 : ●●●●●●●●        <- 이것
```

`192.168.219.1` 바로 옆이나 아래에 있다. 아이디는 `admin` 이다.

라벨이 안 보이거나 지워졌으면 LG U+ 고객센터(101)에 문의한다. 공유기를 초기화하면 기본값으로 돌아가지만, **인터넷 설정까지 초기화되므로 최후의 수단**이다.

## 1-2. 로그인

브라우저에서 `http://192.168.219.1` 접속.

- 아이디: `admin`
- 비밀번호: 라벨의 `웹admin암호`

## 1-3. 비밀번호 변경

**공유기 설정 → 비밀번호 변경**

기본 비밀번호를 쓰는 동안에는 공유기가 보안상의 이유로 포트포워딩 설정을 막는다. 그리고 우리는 인터넷에 포트를 열 예정이므로 어차피 바꿔야 한다.

- 규칙이 강제될 수 있다 (영문 대소문자, 숫자, 특수문자 조합)
- **바꾼 비밀번호를 어딘가에 적어둔다.** 잊으면 공유기 초기화 외에 방법이 없다

# 2. 이 PC에 IP 고정 할당

지금 이 PC는 DHCP로 IP를 받고 있어서 공유기 재부팅이나 시간 경과로 주소가 바뀔 수 있다. 바뀌면 포트포워딩이 죽는다.

**PC에서 수동으로 고정 IP를 잡지 말고, 공유기에서 예약을 거는 편이 낫다.** 설정이 한곳에 모이고, 나중에 다른 기기로 바꿀 때도 여기만 고치면 된다.

메뉴 이름은 펌웨어 버전에 따라 조금 다르다. 다음 중 하나다.

- 네트워크 설정 → DHCP 설정 → 고정 IP 할당
- 네트워크 설정 → 내부 네트워크 설정 → DHCP 예약

입력할 값:

```
MAC 주소 : D8-43-AE-28-0F-76
할당 IP  : 192.168.219.117
```

지금 쓰는 IP를 그대로 예약하면 아무것도 안 바뀌면서 고정만 된다.

---

# 3. 포트포워딩

**네트워크 설정 → NAT 설정 → 포트포워딩 → 추가**

| 항목 | 값 |
|---|---|
| 서비스 이름 | `valheim` (아무거나) |
| 프로토콜 | **UDP** |
| 외부 포트 | `2456` ~ `2457` |
| 내부 IP 주소 | `192.168.219.117` |
| 내부 포트 | `2456` ~ `2457` |

## 주의사항

- **프로토콜은 반드시 UDP다.** 발헤임은 TCP를 쓰지 않는다. TCP로 열면 접속이 안 된다
- 포트 범위 입력란이 하나뿐이면 `2456` 과 `2457` 을 **각각 두 줄로** 추가한다
- `2456` 은 게임 접속, `2457` 은 Steam 쿼리(서버 목록 표시)용이다. 둘 다 필요하다
- **그 외의 포트는 절대 열지 않는다.** 특히 `3389`(원격 데스크톱), `22`(SSH), `445`(파일 공유)는 열면 안 된다

# 4. Wi-Fi 끄기 (PC 쪽)

지금 이 PC는 이더넷과 Wi-Fi가 **동시에** 같은 공유기에 붙어 있다.

```
이더넷  192.168.219.117
Wi-Fi   192.168.219.108
```

포트포워딩은 이더넷(117)으로 거는데 응답이 Wi-Fi(108)로 나가면 접속이 깨질 수 있다. 그리고 게임 서버는 유선이 정답이다. 1 Gbps 유선이 이미 연결되어 있다.

Windows 설정 → 네트워크 및 인터넷 → Wi-Fi → 끄기

무선이 꼭 필요하면 켜둬도 되지만, 접속 문제가 생기면 제일 먼저 의심할 지점이다.

# 5. 설정 확인

공유기 설정이 끝나면 확인한다. 이 단계는 클로드가 도와줄 수 있다.

## 5-1. 내부에서 포트가 열렸는지

서버를 띄운 뒤 PC에서 확인한다.

```powershell
Get-NetUDPEndpoint -LocalPort 2456
```

## 5-2. 외부에서 접근 가능한지

가장 확실한 방법은 **친구에게 접속을 부탁하는 것**이다. 또는 휴대폰 데이터(Wi-Fi 끈 상태)로 테스트한다.

포트 체크 사이트는 UDP를 제대로 못 보는 경우가 많으니 너무 믿지 않는다.

## 5-3. 안 될 때 확인 순서

1. Windows 방화벽이 막고 있는가 (인바운드 규칙에 UDP 2456-2457 허용 필요)
2. 프로토콜을 TCP로 잘못 넣었는가
3. 내부 IP가 바뀌었는가 (`ipconfig` 로 확인)
4. 서버 컨테이너가 실제로 떠 있는가
5. 공유기가 이중 NAT 환경인가 (공인 IP 확인됨: 아님)

# 6. 나중에: Wake On LAN (지금은 안 해도 됨)

밖에서 PC를 깨워 서버를 켜고 싶을 때 설정한다. **서버가 안정적으로 돌아가는 것을 확인한 뒤에 한다.**

## 공유기 쪽

좌측 하단 **Wake On LAN** 메뉴에서 이 PC를 등록한다.

```
MAC 주소 : D8-43-AE-28-0F-76
```

`원격제어 설정` 탭이 있으면 외부에서도 깨울 수 있는지 확인한다.

## Windows 쪽 (클로드가 처리 가능)

- 고속 시작 끄기 (현재 켜져 있어 완전 종료 상태에서 WOL 이 안 된다)
- 네트워크 어댑터 전원 관리에서 "매직 패킷에서만 깨우기" 활성화

## BIOS 쪽 (직접)

재부팅 후 BIOS 진입. AMD 보드 기준 항목 이름이다.

- `Power On By PCI-E` 또는 `Wake on LAN` -> Enabled
- `ErP Ready` -> **Disabled** (켜져 있으면 절전 중 랜카드 전원이 끊긴다)
- `RTC Alarm` -> 예약 부팅이 필요하면 Enabled

## 왜 완전 종료가 아니라 절전인가

| | 완전 종료 (S5) | 절전 (S3) |
|---|---|---|
| 소비전력 | 0.5W | 3~5W |
| 월 전기료 | 거의 0 | 수백 원 |
| WOL 신뢰성 | 불안정 | 높음 |
| 깨어나는 속도 | 1~2분 | 5~10초 |

월 수백 원으로 신뢰성을 산다. 출근할 때 PC를 끄지 말고 절전으로 두는 것을 권한다.
