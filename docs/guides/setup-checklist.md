# 1단계. 무료 체험판 활성화

https://console.cloud.google.com/freetrial 로 간다.

- [ ] 구글 계정으로 로그인
- [ ] 국가 선택, 약관 동의
- [ ] 결제 수단(카드) 등록

**카드를 등록해도 90일 후 자동으로 결제되지 않는다.** 크레딧을 다 쓰거나 90일이 지나면 그냥 멈춘다. 유료 전환은 명시적으로 버튼을 눌러야만 된다.

받는 것: **$300 크레딧, 90일**. 둘 중 먼저 끝나는 쪽에서 종료된다.

> 이미 예전에 무료 체험판을 썼던 계정이면 다시 받을 수 없다. 그 경우 다른 구글 계정을 쓰거나, 유료 계정으로 진행해야 한다. 우리 구성은 온디맨드라 유료로 가도 월 2~3만원 수준이다.

# 2단계. 프로젝트 만들기

https://console.cloud.google.com/projectcreate 로 간다.

- [ ] 프로젝트 이름 입력 (예: `valheim-server`)
- [ ] 만들어진 **프로젝트 ID**를 적어둔다

**프로젝트 ID는 이름과 다를 수 있다.** 이름이 `valheim-server`여도 ID는 `valheim-server-473812` 처럼 숫자가 붙는다. 화면에 표시되는 정확한 ID를 알려주면 된다.

- [ ] 프로젝트에 결제 계정(무료 체험판)이 연결되어 있는지 확인

# 3단계. 예산 알림 걸기

크레딧이 얼마나 남았는지 모르고 지나가는 것을 막는다. 3분이면 된다.

https://console.cloud.google.com/billing 에서 결제 계정 선택 후 "예산 및 알림".

- [ ] 예산 만들기
- [ ] 금액: **$100**
- [ ] 알림 임계값: 50%, 90%, 100%
- [ ] 이메일 수신 확인

$100을 잡는 이유: 우리 설계의 90일 예상 비용이 약 $127이다. $100 예산의 50%인 $50에서 첫 알림이 오면 "절반쯤 왔구나"를 알 수 있다.

# 4단계. 로그인

1, 2단계가 끝났으면 **"1, 2단계 끝났어, 프로젝트 ID는 OOO야"** 라고 알려주면 된다.

그러면 클로드가 로그인 명령을 실행하고 브라우저를 띄운다. 할 일은 이것뿐이다.

- [ ] 브라우저에서 구글 계정 선택
- [ ] "허용" 클릭
- [ ] 한 번 더 (총 2회. 두 번째는 Terraform이 쓸 자격증명이다)

계정 인증은 대신 눌러줄 수 없는 부분이라 직접 해야 한다.

# 5단계. 서버 구축 (대기만 하면 됨)

여기서부터 클로드가 진행한다. 순서는 이렇다.

1. **사전 검증**: vCPU 할당량, 실제 단가, 필요 포트, 모드 버전 확인
2. **인프라 생성**: `terraform apply` 로 네트워크, 버킷, VM 생성 (**여기서 과금 시작**)
3. **서버 첫 기동**: 발헤임 서버를 띄우고 `status.json` 실제 응답을 캡처
4. **파서 작성**: 캡처한 실제 응답을 기준으로 접속 인원 파싱 로직 TDD
5. **자동 종료 구현**: 유휴 감시 스크립트 작성 및 배포

중간에 확인이 필요하면 물어본다. 특히 **`terraform apply` 직전에 생성될 리소스 목록을 보여주고 승인을 받는다.** 과금이 시작되는 지점이기 때문이다.

# 6단계. 월드 이전 (대기만 하면 됨)

친구 월드 `gaybar` 를 서버에 올린다. 분석은 이미 끝났다.

- 형식: 1.0 폴더 형식 (변환 불필요)
- 월드 이름: `gaybar`
- 크기: 4.19 MB
- 올릴 파일: 이미 올바른 구조로 준비해둠

원본 `gaybar.zip` 은 **이전이 확인될 때까지 지우지 않는다.**

# 7단계. 접속 테스트 (직접 해야 함)

서버가 뜨면 발헤임을 켜고 직접 들어가서 확인한다.

- [ ] 발헤임 실행, "서버 참여" 또는 "서버 추가"
- [ ] 알려준 IP 주소와 포트 입력 (예: `34.64.123.45:2456`)
- [ ] 비밀번호 입력
- [ ] 접속 성공 확인

들어가서 볼 것:

- [ ] 짓던 건축물이 그대로 있다
- [ ] 상자 안의 물건이 그대로다
- [ ] 잡았던 보스의 제단 상태가 유지된다
- [ ] 포탈이 연결된다

지도가 비어 보이는 것은 정상이다. **지도 탐험 기록은 월드가 아니라 캐릭터에 저장된다.**

그다음 자동 종료를 확인한다.

- [ ] 게임에서 나간다
- [ ] 약 20분 뒤 서버가 스스로 꺼지는지 확인 (클로드가 같이 본다)

# 8단계. 친구들에게 공유

- [ ] 접속 주소와 비밀번호 전달
- [ ] **로컬 월드를 더 이상 열지 말 것** 전달 (열면 월드가 갈라져 합칠 수 없다)
- [ ] 원본 월드 파일은 보관만 하고 지우지 말 것 전달
- [ ] 캐릭터는 쓰던 것 그대로 들어오면 된다고 전달 (아무것도 안 해도 됨)

# 궁금할 만한 것

**Q. 카드에서 돈이 나가나?**
아니다. 무료 체험판은 90일 또는 $300 소진 시 그냥 멈춘다. 유료 전환 버튼을 직접 눌러야만 과금된다.

**Q. 서버를 안 켜두면 친구들이 못 들어오는 거 아닌가?**
맞다. 그래서 웹앱을 만든다(서브프로젝트 C). 친구가 웹에서 버튼을 누르면 1~2분 내로 기동된다. 예약도 걸 수 있다. 다만 웹앱은 서버가 안정화된 뒤에 만든다.

**Q. 90일 뒤에는?**
세 가지 중 고르면 된다. 유료 전환(월 2~3만원), 백업만 회수하고 정리, 다른 곳으로 이전. 월드 백업이 GCS 버킷에 따로 쌓이도록 설계해서 어느 쪽이든 데이터는 안전하다.

**Q. 모드는 언제 넣나?**
서버가 바닐라로 안정적으로 돌아가는 것을 확인한 뒤다(서브프로젝트 B). 모드 문제와 인프라 문제를 동시에 겪으면 원인을 구분할 수 없다.
